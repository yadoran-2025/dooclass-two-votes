## 사용자 요청과 구현 범위

- 확정 요청: 1인 2표로 투표하고 국회 구성을 쉽게 관찰한다. 축소 가상 국회 대신 전국 규모로 구현한다. 정당·후보 이름은 수업용을 사용한다(2026-10-25).
- 구현 기준: **제22대 총선(2024)의 실제 17개 시도·254개 지역구**, 지역구 254석 + 비례대표 46석 = 300석. 선거구 명칭은 선관위 공개 파일에서 추출했다. 시도별 수는 서울 48, 부산 18, 대구 12, 인천 14, 광주 8, 대전 7, 울산 6, 세종 2, 경기 60, 강원 8, 충북 8, 충남 11, 전북 10, 전남 10, 경북 13, 경남 16, 제주 3이다.
- 제작 제안: 전국 세 정당이 각각 지역구 후보와 비례명부를 내는 수업 상황이다. 이름·나이·정당·득표·결과는 수업용이다. 실제 2024년 후보나 개표 결과의 재현, 현재 의원 현황, 미래 선거 예측이 아니다.
- 디자인은 두 작동 화면을 비교한 뒤 사용자가 고른 B안 ‘개표 방송’으로 확정했다(2026-10-25). 남색 바탕·노란 강조를 투표·지역 선택·개표·국회 구성에 일관되게 적용한다. 미사용 안과 비교 페이지는 정리했다.

## 수업 흐름

1. ‘내 지역구’를 눌러 시도 버튼 또는 이름 검색으로 지역구를 찾는다.
2. 흰 용지에서 지역구 후보 한 명, 연두 용지에서 정당 한 곳을 선택한다. 후보 소속과 다른 정당을 선택할 수 있다.
3. ‘두 표 투표하기’로 각 표를 별도로 집계한다. 선택만으로 투표하거나 결과를 드러내지 않는다. 여러 사람이 같은 기기에서 이어서 투표할 수 있다. 각 사람을 식별·저장하지 않는다.
4. ‘개표하고 국회 구성 보기’에서 지역구 당선인 → 비례대표 배분 → 국회 300석을 확인한다. 지역구 결과는 실제 254개 선거구 경계 지도에 표시하며 경계를 누르면 당선인·득표를 확인한다. 전국·서울·부산·선택 지역 확대 버튼과 드래그·휠·키보드를 지원한다. 검색한 선거구는 자동 확대한다. 닫기·Escape 후 결과·마지막 장면·지도 범위를 보존하고 다시 볼 수 있다. 새 표를 넣으면 다음 개표에서 다시 계산한다.
5. 전국을 빠르게 관찰하려면 ‘나머지 지역 예시 표 채우기’를 사용한다. **투표가 전혀 없는 지역에만** 100명씩 예시의 두 표를 추가한다. 이미 투표한 지역·직접 투표는 보존한다. 예시와 직접 투표 인원을 구분해 표시한다. 예시 득표는 시범을 위한 고정 규칙으로 만들며 실제 지역별 정치 성향을 나타내지 않는다.

투표가 없는 지역구는 지도에서 회색 경계로 표시한다. 전국 지역구 결과가 정해지기 전에는 지역구 결과와 연동되는 비례대표 배분을 확정하지 않는다. 300개 자리 중 구성된 자리와 대기 자리를 구분한다. 새로고침하면 초기화되며 ‘새 선거 시작’은 확인 후 표를 모두 지운다.

지역구 결과는 사용자의 지도 요청(2026-10-25)에 따라 시도별 의석 칸에서 실제 선거구 지도로 바꿨다. 각 선거구는 한 석이며 지도 면적과 의석수는 비례하지 않는다는 안내를 표시한다. 해안선 등을 단순화한 시각화용 지도이며 지적 측량용이 아니다. 제주·서해 도서·울릉도 등은 원본과 동일한 좌표계에 표시하며 임의의 위치로 옮기지 않는다. 지도 자체는 앱에 포함되어 오프라인에서도 동작한다.

## 배분 방식과 단순화

제도 재현 기준은 **2024년 제22대 총선**이다. 2026년 이후 법령·헌법재판 결정이나 다음 선거의 개편을 자동 반영하는 앱이 아니다. 화면에 기준 연도를 표시한다.

지역구는 각 지역 유효표 최다 후보 한 명을 당선시킨다. 최고 득표가 같으면 수업용 나이가 더 많은 후보를 택한다. 수업 후보의 나이는 지역 내에서 서로 다르다. 지역구마다 후보는 세 명이며 무소속·사퇴·등록무효·무투표 당선·보궐선거는 넣지 않았다.

비례대표는 2024년의 준연동 배분을 구현했다. 당시의 의석할당 기준인 정당 유효표 3% 이상 또는 지역구 5석 이상을 적용하고, 할당정당 득표 합계로 비율을 구한다. 할당정당 이외의 지역구 당선인을 전체 300석에서 제외한 뒤, 정당 비율에 따른 몫에서 지역구 당선 의석을 빼고 절반을 반올림해 연동 의석을 산출한다. 음수는 0석이다. 합계가 46석보다 적으면 남은 자리를 득표 비율로 추가하고, 넘으면 연동 의석 비율로 46석에 맞춰 조정한다. 정수 우선 배분 후 최대 잔여 방식으로 배분하며 배분 경계가 동률이면 수업용 무작위 추첨을 한다. 한 번 개표한 결과는 표가 바뀔 때까지 유지한다.

각 당에 충분한 비례명부 후보가 있다고 가정한다. 위성정당·선거연합·후보 부족에 따른 공석·비례 승계·의원 이동을 재현하지 않는다. 화면의 번호는 정당의 명부 순위이며 유권자가 특정 비례후보 개인을 선택한 것이 아니다. 복잡한 계산은 교사용 문서에 두고 화면에서는 두 투표의 경로와 의석의 소속에 집중한다.
